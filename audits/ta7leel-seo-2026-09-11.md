# Ta7leel SEO follow-up — 11 September 2026

## New confirmed issue

`/connections/` (Ideas in the Wild) returned HTTP **404**, a `Page not found` title, and `noindex, follow` on the public website during this audit. The live `sitemap.xml` returned 200 and explicitly listed that URL. React defines the page, but the production build did not write its HTML and Netlify had no explicit route for it. Client navigation could display the page while a direct request failed.

Implemented locally:

- Prerender the actual Ideas React component through StaticRouter, preserving all existing field notes and book links.
- Load its generated CSS in the initial HTML so the prerender retains the existing page styling.
- Share title, description and keywords between the runtime page and prerender; include canonical URL, CollectionPage and breadcrumb markup in the generated HTML.
- Add build regression checks for Ideas content/styles and for every sitemap URL having a static HTML file or an explicit 200 route in Netlify configuration. Existing generic SPA exceptions remain visible; this is not a substitute for deployment-level HTTP tests.

The two new tests reproduced the issue before implementation: missing `dist/connections/index.html` and an unsupported `/connections` sitemap route. No design changes, editorial rewrites, publishing, commits, or pushes were performed.

## Current Google guidance

There is no need to add a special AI text file or special schema to qualify for Google's AI search features. Google continues to emphasize indexability, crawlable internal links, accessible text, useful content and structured data that matches the visible page. [Google Search Central: AI features and your website](https://developers.google.com/search/docs/appearance/ai-features).
