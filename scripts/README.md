# BookBriefs Library System

This folder contains the book library management system for BookBriefs. Each book is defined in its own TypeScript file, providing type safety, autocomplete, and easy version control.

## 📁 Structure

```
scripts/
├── types.ts                  # Type definitions (BookDefinition, SyncResult, etc.)
├── sync-library.ts          # Main sync script to upload books to Firestore
└── library/                 # Individual book definition files
    └── how-i-made-2000000-in-the-stock-market.ts
```

## 🚀 Quick Start

### 1. Set Up Admin Access

First, get your Firebase Auth UID and update the firestore rules:

1. Sign in to your BookBriefs app
2. Open browser console and run: `firebase.auth().currentUser.uid`
3. Copy the UID
4. Update `firestore.rules` line 14: Replace `'YOUR_FIREBASE_AUTH_UID'` with your actual UID
5. Deploy the rules:
   ```bash
   firebase deploy --only firestore:rules
   ```

### 2. Add a New Book

Create a new file in `scripts/library/` named after your book (use kebab-case):

```typescript
// scripts/library/your-book-name.ts
import { BookDefinition } from '../types.js';

export const book: BookDefinition = {
  id: 'your-book-name',
  title: 'Your Book Title',
  author: 'Author Name',
  category: 'Finance', // or 'Business', 'Self-Help', 'Trading', etc.
  coverImageUrl: '/images/your-book-cover.jpg',
  rating: 4.5,
  publicationYear: 2024,
  pageCount: 300,
  arabicSlug: 'arabic-slug-here',
  isPremium: false,
  summary: `
    # Executive Summary
    Your detailed book summary here...
  `,
  keyTakeaways: [
    "First key takeaway with **bold** text",
    "Second key takeaway",
    // ... more takeaways
  ],
  translations: {
    en: {
      title: 'Your Book Title',
      author: 'Author Name'
    }
  }
};
```

### 3. Sync to Firestore

Run the sync script to upload all books to Firestore:

```bash
npm run sync-library
```

You'll be prompted for your email and password. The script will:
- ✅ Authenticate with Firebase
- 📖 Load all books from the library folder
- ✔️ Validate each book definition
- 🔄 Upload new books or skip existing ones
- 📊 Show a summary of what was synced

### 4. Update Existing Books

To update a book that's already in Firestore, use the `--force` flag:

```bash
npm run sync-library -- --force
```

## ✨ Features

### Type Safety
TypeScript autocomplete helps you avoid errors:
```typescript
category: 'Finance'  // ✅ Valid
category: 'finance'  // ❌ TypeScript error
```

### Validation
The sync script validates all fields before uploading:
- Rating must be between 0-5
- Summary must be at least 100 characters
- Publication year must be > 1000
- All required fields must be present

### Automatic Search Terms
The script automatically generates search terms from:
- Title words
- Author words
- Category
- Full title and author

This improves discoverability in the app's search feature.

## 🎯 Best Practices

1. **One Book Per File**: Keep each book in its own file for easy version control
2. **Descriptive Filenames**: Use kebab-case matching the book's ID
3. **Complete Summaries**: Aim for 3,000-8,000 word summaries with proper structure
4. **Rich Takeaways**: Include 15-20 detailed key takeaways with formatting
5. **Verify Assets**: Ensure cover images and PDFs exist before syncing
6. **Test First**: Run sync without `--force` first to see what would happen
7. **Regular Backups**: The Firestore database is your source of truth, but these files serve as version-controlled backups

## 🔧 Troubleshooting

### "7 PERMISSION_DENIED" Error
- Make sure you updated `firestore.rules` with your Firebase Auth UID
- Deploy the rules: `firebase deploy --only firestore:rules`
- Verify you're signing in with the correct admin email

### "Validation failed" Error
- Check that all required fields are present
- Verify rating is between 0-5
- Ensure summary is at least 100 characters
- Confirm category matches one of the allowed values

### Book Not Appearing on Website
- Clear browser cache and sessionStorage
- Verify book was created in Firestore (check Firebase Console)
- Ensure book has both `id` and proper data structure
- Check browser console for any errors

### "Cannot find module" Error
- Make sure you're using `.js` extensions in imports (not `.ts`)
- Verify `tsx` is installed: `npm install tsx`
- Check that `type: "module"` is in `package.json`
